# UNEZUS Academy

Previa premium de uma plataforma de educacao continuada em ultrassonografia para a marca UNEZUS.

## Stack

- React
- TypeScript
- Vite
- Tailwind CSS

## Principais areas da demo

- Landing page publica
- Login demo
- Area do aluno
- Pagina de aulas
- Especialidades
- Calendario de conteudos
- Biblioteca de laudos
- Estudos de caso
- Ranking e perfil
- Painel administrativo

## Como rodar

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Observacoes

- Os dados sao mockados
- Parte dos estados fica salva em `localStorage`
- A demo foi pensada para apresentacao comercial e validacao visual
